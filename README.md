# Python Practice Projects

This repository contains several small Python projects created while learning programming.

## Projects

### Algorithms
- astar_pathfinding.py — implementation of the A* pathfinding algorithm for finding the shortest path in a grid.

### Math
- factorial_calculator.py — calculates the factorial of a number.
- sum_1_to_n.py — calculates the sum of numbers from 1 to N.

### Basics
- transport_decision.py — simple program that helps choose transportation based on conditions.

### Games
- tetris_game.py — simple Tetris game implementation.
- breakout_game.py — simple Breakout arcade game.

These projects were created for learning Python fundamentals such as loops, conditions, algorithms, and basic game logic.
